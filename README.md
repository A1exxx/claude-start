# Настройка Claude Code для презентаций, видео, картинок и сайтов

Три шага, около 20 минут.

1. **Приложение.** Скачайте Claude для компьютера: https://claude.com/download. Войдите своим аккаунтом
   (нужен платный тариф Pro или выше) и откройте вкладку **Code**. Рабочая папка — «Документы».
2. **Текст настройки.** Откройте [prompt.txt](prompt.txt), нажмите кнопку «Copy raw file» (два квадратика справа сверху),
   вставьте в Claude Code и отправьте.
3. **Отвечайте «да».** Claude сам поставит программы и скиллы, запишет правила, сделает пробную презентацию и ролик.
   В конце перезапустите приложение.

## Что получится
- Презентации PowerPoint и PDF с картинками на каждом слайде: фото из бесплатных фотобанков, схемы и сгенерированные иллюстрации.
- Короткие ролики с русской озвучкой и субтитрами — для Reels, Shorts, YouTube.
- Документы Word, таблицы Excel, гайды и чек-листы.
- Лендинги и простые сайты в современном дизайне.
- Claude не отказывается, а ищет способ; без вашего «да» ничего не публикует, не удаляет и не тратит деньги.

После настройки откройте файл `.claude/CLAUDE.md` в папке пользователя и впишите три строки в раздел «Кто я»:
роль, для кого материалы, ваш стиль.
