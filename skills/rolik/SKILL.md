# Ролик под ключ

1. **Задача** (спроси только недостающее): о чём ролик, для кого, где выйдет (Reels/TikTok — 9:16, YouTube — 16:9),
   длина (15–30 с для соцсетей, до 2 мин для объяснения), нужен ли голос.
2. **Сценарий** — таблица «секунды → что на экране → что говорит голос». Первые 2 секунды цепляют: вопрос, цифра или
   результат. Покажи сценарий и жди «да».
3. **Кадры** — по правилам раздела «Картинки» из CLAUDE.md: фото из бесплатных фотобанков, графика кодом, иллюстрации
   генерацией. Текст на кадре крупный, не больше 7 слов, не у краёв.
4. **Озвучка** — edge-tts (русские голоса ru-RU-SvetlanaNeural, ru-RU-DmitryNeural). Длину кадров подгони под голос.
5. **Сборка** — скиллы HyperFrames (видео из HTML, плавные анимации) или ffmpeg (слайд-шоу с плавными переходами).
   Субтитры по словам, без перекрытия важного.
6. **Проверка** — 5–6 снимков из разных мест ролика и прослушивание: нет обрезанного текста, голос совпадает с кадром,
   звук не обрывается. Нашёл ошибку — исправь и проверь снова.
7. **Сдача** — MP4 в `Документы/Claude/<дата>_<тема>/`, открой файл, напиши длину, формат и что проверить.
